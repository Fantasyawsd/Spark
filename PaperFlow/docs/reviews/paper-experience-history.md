# PaperFlow 论文与社区体验改造历史记录

> 历史状态：本文记录早期四栏导航和社区方案，不是当前产品契约，也不作为后续开发入口。当前生产导航和持续计划以根 `README.md`、`docs/development-roadmap.md` 及 `docs/product/` 为准。

> 目标：减少视觉层级和强调色，围绕“快速判断论文价值、阅读摘要或 PDF、收藏/评论/AI 解读”建立清晰主行动线，并让社区页复用同一套颜色、图标、分段控件和底部 Dock 规范。
>
> 本文是实现与验收基线。每个阶段只修改已经验证的公共能力，避免一次性重写论文流和社区业务结构。

## 1. 设计原则

- 强调色只保留给激活状态、AI 解读入口和关键命令；正文、导航、搜索与筛选使用中性色。
- 论文页默认优先展示标题、作者/单位、来源/年份/引用和 PDF 入口；社交操作降级为底部辅助动作。
- 摘要收起状态不承载独立滚动；展开后进入独立阅读页，避免与论文上下翻页手势竞争。
- Markdown、LaTeX 和 AI 输出统一经过同一条渲染链路，解析失败时优先保证纯文本可读。
- 论文操作栏的点赞、评论、收藏、分享数量始终显示，引用数也始终显示；不擅自隐藏既有数据。
- 论文页和社区页共用颜色、图标状态、顶部高度、分段控件和 Dock 组件。

## 2. 公共视觉规范

### 2.1 颜色

| 用途 | 规则 |
| --- | --- |
| 主强调色 | 五套低饱和方案：蔷薇、学术蓝、鸢尾紫、松石绿、琥珀 |
| 页面背景 | 冷中性浅灰 `canvas`，与白色阅读面形成稳定层级 |
| 论文正文 | 深灰蓝 `ink`，避免纯黑造成的生硬对比 |
| 元信息/时间/引用 | 中性灰 `muted`；次要提示使用更浅的 `subtle` |
| 边界与输入面 | `line`、`surfaceMuted` 和 `surfaceStrong` 统一管理 |
| 错误状态 | 独立 `danger` / `dangerSoft`，不随用户主题色改变 |
| 搜索/筛选 | 深色或中性色，不使用玫红 |
| 未关注 | 中性色描边 |

主题切换只改变语义强调色及其浅色容器，不改变正文、页面底色和错误色。所有主色与白色按钮内容保持至少 4.5:1 对比度；旧主题枚举名称保持不变，已有本地偏好无需迁移。

### 2.2 图标与触控

- 操作栏图标 22–24px，点击区域至少 44×44px。
- 未选中使用线性图标，选中使用填充图标；论文入口保留“论文 ⇄ / ‹ 返回”的双向浏览提示。
- Dock 统一为“论文、社区、聊天、我的”，未读默认显示小圆点。
- 中间发布 FAB 尺寸和位置保持稳定，避免与 AI 入口争夺注意力。

## 3. 论文页信息结构

```text
标题
作者 等 · 第一单位                         关注作者
arXiv    2026 年发布    被引 12
查看 PDF ↗
[ 原文 | 中文解读 | 相关论文 ]
正文
                         ✨ AI 解读
点赞   评论   收藏   分享
```

- 作者行不再拼接重复的 `· arXiv`。
- “关注作者”明确表达关注对象；论文保存由“收藏”承担。
- 引用、点赞、评论、收藏、分享数量始终显示，包括 0。
- PDF 优先使用 `pdfUrl`，无 PDF 时回退到 `paperUrl`；没有有效链接则不显示入口。

## 4. Markdown / LaTeX 渲染契约

所有原文摘要、中文解读、AI 回复、相关论文都必须使用 `PaperMarkdown`：

1. 支持 `$...$` 行内公式和 `$$...$$` 块公式。
2. 流式输出遇到不完整分隔符时暂时补齐，最终内容不被永久改写。
3. 对常见的残缺或混用分隔符进行预处理。
4. 解析失败时去掉 `$` 和反斜杠分隔符，保留可读纯文本；常见符号可回退为 `ε、θ、∞` 等 Unicode。
5. Markdown 的可选文本仍保持可选择；标题复制不依赖正文滚动。

## 6. 验收清单

- 页面中玫红重点不超过 3 处。
- 原文、中文解读、AI 回复和相关论文不出现裸露 LaTeX 分隔符。
- 论文引用和底部操作数量完整显示，包括 0。
- 摘要收起状态不能内部滚动，展开后可完整滚动和选择文本。
- PDF 入口在标题/元信息附近一眼可见。
- AI 与社交操作有明确分区。
- 关注按钮写为“关注作者”。
- Dock 保留“论文 ⇄ / ‹ 返回”双向切换，其他图标状态统一。
- 论文页和社区页顶部高度、颜色、图标尺寸一致。
- 外层论文翻页不再与摘要滚动冲突。

## 7. 本轮实现边界

本轮优先落地 P0 和 P1 的低风险公共能力：渲染预处理、元信息、完整计数显示、原文与中文解读展开阅读、PDF 入口、分段控件、AI 与操作栏分离、Dock 图标和未读圆点。社区业务结构和上滑动效保留在后续阶段。应用内 PDF 阅读器明确不做，PDF 统一交给系统浏览器打开。
