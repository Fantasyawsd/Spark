# PaperFlow V1.0 当前进度审计

> 审计日期：2026-08-01
> 目标版本：`1.0.0+1`
> 第一验收平台：Android
> 状态：功能收敛中，尚不是可发布候选版本

## 1. 范围冻结

V1.0 只交付三个一级页面：

1. **论文**：论文发现、搜索、阅读、翻译、相关论文和本地互动。
2. **ChatPaper**：主聊天、论文聊天、流式回答、深度思考、联网搜索和本地会话。
3. **我的**：收藏分组、阅读记录、AI 凭据、主题、本地数据管理和应用信息。

社区、帖子、用户私信、系统通知、账号、云同步和内容发布不进入 V1.0。源码可以暂时保留，但不得出现在生产导航、页面入口或占位统计中。

## 4. 已确认的技术决策

### 远程论文

- 手机端使用 arXiv Atom 查询 API，不把 OAI-PMH 全量同步放入启动流程。
- arXiv Provider DTO、缓存 Record 和领域 `Paper` 必须是不同类型。
- 使用小页分页并缓存；连续 arXiv 请求遵守服务方的节流要求。
- V1 保持去除版本后缀的裸 arXiv ID，例如 `2404.01356`，避免破坏现有收藏和评论关联。
- OpenAlex 只做非阻塞增强，不影响论文正文加载。

### DeepSeek

- Endpoint、模型和协议参数可以固定，公开 APK 不包含共享 API Key。
- V1 使用用户自己的 Key；正式实现通过安全凭据 Repository 访问 Android Keystore。
- `dart-define` 只允许私人开发构建回退，不属于上线方案。
- 深度思考关闭时不发送思考预算；开启时默认使用 `high`。
- 聊天、思考内容、评论和阅读记录是设备上的明文本地数据，必须在隐私说明中明确并提供删除入口。
