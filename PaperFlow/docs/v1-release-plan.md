# PaperFlow V1.0 单机版发布计划

> 状态：执行中
> 最近更新：2026-08-01
> 第一验收平台：Android 手机

## 1. V1.0 产品范围

V1.0 只保留三个一级界面：

1. **论文**：远程论文流、分类、搜索、阅读、翻译、点赞、收藏、评论和分享。
2. **AI 聊天**：置顶主聊天、按论文建立的聊天、流式回答、深度思考、联网搜索和本地会话管理。
3. **我的**：收藏、阅读历史、稍后阅读、主题、AI 凭据、本地数据和应用信息。

以下能力不进入 V1.0：

- 社区信息流、发帖和社区互动；
- 用户私信、系统通知和未读提醒；
- 账号、云同步和跨设备状态；
- 论文上传、内容发布和审核。

现有 `community` 和旧消息模块暂时保留源码，但不进入正式导航和生产组合根。确认 V1.0 稳定后再决定归档或删除，避免在收敛阶段进行无关的破坏性清理。

## 2. 架构整改顺序

远程功能接入前先完成以下结构调整：

1. 领域层使用 `Paper`，不再以数据库语义的 `PaperRecord` 作为业务实体。
2. 作者使用结构化列表，计数使用整数；紧凑数字只在展示层格式化。
3. 论文正文和统计值使用独立领域值对象，远程 JSON 由数据层 DTO/Mapper 转换。
4. `PaperRepository` 升级为异步、分页接口；Widget 只依赖 Controller 状态。
5. 远程、缓存和种子数据分别作为 Repository Adapter，由组合根选择和组装。
6. AI 凭据通过独立端口读取，DeepSeek Adapter 不直接读取页面状态或本地文件。

每次整改必须保持现有功能，执行 `dart analyze`、相关测试、全量 `flutter test` 和 `git diff --check`，并使用原子提交。

## 3. 远程论文数据源

V1.0 采用客户端可直接访问的公开论文源，首选 arXiv 搜索/详情接口。OpenAlex 只作为可选的引用数和概念增强源，不阻塞论文阅读。

Repository 对外提供：

- 推荐、最新和领域筛选；
- 关键词搜索；
- 游标或页码分页；
- 下拉刷新和下一页预加载；
- 论文详情查询；
- 缓存优先、远程更新；
- 无网时回退到最近缓存或内置种子；
- 明确的加载、空结果、网络错误和重试状态。

数据链路：

```text
远程 JSON/XML -> Provider DTO -> Mapper -> Paper
                                  ↓
                         版本化本地缓存 Record
```

远程 DTO、缓存 Record 和领域 `Paper` 不共用同一个类型。

## 4. DeepSeek 配置与密钥

DeepSeek 的接口地址、模型标识和协议版本可以作为应用常量固定；**可公开分发的 APK 不硬编码共享 API Key**。APK 中的字符串和编译常量可被提取，硬编码 Key 会导致额度盗用，无法满足“可上线”要求。

V1.0 单机版采用 BYOK：

- 用户在“我的 > AI 设置”中输入 DeepSeek API Key；
- Key 使用 Android Keystore 支持的安全存储，不写普通 JSON、不提交 Git；
- 页面只显示掩码和连接状态；
- 支持验证、替换和删除 Key；
- 未配置或鉴权失败时提供明确引导；
- Endpoint、模型和默认请求参数由代码固定；
- 私人开发构建可以继续使用 `--dart-define` 作为调试回退，但不作为商店发布方案。

如果未来改为所有用户共享平台额度，必须增加服务端代理、鉴权、限流和额度控制。

## 6. 发布验收

- 冷启动有本地内容；联网后自动更新，不因远程失败进入空白页。
- 三个一级页面高度和 Dock 状态稳定，不出现未实现入口。
- 所有本地状态在重启后恢复，损坏数据可隔离并回退。
- 未配置 Key 时论文浏览完全可用，AI 页面提供配置引导。
- AI 请求支持流式、停止、重试；密钥不会出现在日志、普通文件或 Git diff 中。
- 无社区、私信、通知、发布按钮或相关占位文案。
- `dart analyze`、全量 `flutter test` 和静态发布检查通过。
- Android 真机完成网络、键盘、分享、后台恢复和低网速人工验收。
