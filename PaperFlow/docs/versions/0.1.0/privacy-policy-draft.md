# PaperFlow 隐私政策草案

> 状态：发布前草案。上架或公开分发前，必须补充运营者名称、联系邮箱和可公开访问的 HTTPS 地址；在此之前不得把本文件当作正式隐私政策。
>
> 最近更新：2026-08-01

## 1. 适用范围

本政策适用于 PaperFlow 0.1.0 Android 应用。0.1.0 不提供账号、云同步、广告或行为分析服务。

## 2. 本地处理的数据

应用在设备本地保存论文缓存、阅读记录、点赞、收藏分组、评论、搜索历史、中文解读和 ChatPaper 会话。该等内容用于恢复用户的阅读与聊天状态。用户可以在“我的 > 本地数据”中分类清理或重置业务数据。

DeepSeek API Key 使用操作系统安全存储保存，不写入普通 JSON 业务数据。用户可在“我的 > AI 设置”验证、替换或删除该 Key。应用禁用 Android 自动备份。

## 3. 发送给第三方的数据

论文目录和搜索请求会发送给 arXiv，用于获取公开论文元数据。

当用户主动使用 ChatPaper、中文解读或联网搜索时，应用会向 DeepSeek 官方 API 发送用户输入、当前论文的标题、摘要和必要的对话上下文，以及用户自行提供的 API Key，用于生成回复或译文。启用联网搜索时，DeepSeek 会处理搜索请求并向应用返回来源。

打开论文、PDF 或来源链接时，应用会交由系统浏览器处理；相应网站按其自身政策处理数据。

## 4. 保留与删除

设备本地数据保留至用户通过应用清理、卸载应用或清除应用数据。DeepSeek 和 arXiv 对请求日志、保留和处理的规则由其自身的公开政策决定；PaperFlow 不控制第三方的保留期限。

## 5. 数据安全

应用只申请网络权限，禁用明文网络流量和 Android 自动备份。尽管如此，用户应妥善保管自己的 DeepSeek API Key，且不应在聊天输入中提交不适合发送给第三方服务的敏感信息。
