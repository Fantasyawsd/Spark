# PaperFlow 0.1.0 当前进度审计

> 审计日期：2026-08-01
> 目标版本：`0.1.0+1`
> 第一验收平台：Android
> 状态：功能代码候选，尚不是发布候选版本

## 1. 范围冻结

0.1.0 只交付三个一级页面：

1. **论文**：论文发现、搜索、阅读、翻译、相关论文和本地互动。
2. **ChatPaper**：主聊天、论文聊天、流式回答、深度思考、联网搜索和本地会话。
3. **我的**：收藏分组、阅读记录、AI 凭据、主题、本地数据管理和应用信息。

社区、帖子、用户私信、系统通知、账号、云同步和内容发布不进入 0.1.0。源码可以暂时保留，但不得出现在生产导航、页面入口或占位统计中。

## 2. 已完成

### 论文

- arXiv Atom 远程论文目录已进入生产组合根，启动先用内置种子保证首屏，随后异步更新远程或缓存数据。
- 远程搜索、分页加载、论文详情查询、版本化论文缓存和离线回退已经有自动化测试覆盖。
- 推荐领域会映射到 arXiv 分类并进入远程 Feed 查询；筛选切换期间的过期响应不会覆盖当前列表。
- “全部”和“最新”使用明确的产品领域合集，避免 arXiv `all:*` 查询返回 HTTP 500；服务端 5xx 会按三秒节流规则重试一次，最终失败时显示本地数据和用户可理解的降级提示。
- 单页在剩余 10 篇时预取下一页，双栏接近滚动边界时加载下一页；刷新结果置顶、分页结果追加，并按稳定论文 ID 去重。
- 单页垂直信息流和双栏选择模式。
- 首页 Feed 与外部全屏论文详情使用不同导航视角。
- Markdown、LaTeX、可选正文、滚动和溢出展开。
- 原文、中文解读和相关论文。
- 点赞、收藏分组、关注、评论、回复、分享、已读和稍后阅读。
- 论文操作栏“更多”使用紧凑圆角菜单，保留已读和稍后阅读原有命令。
- 收藏、评论、阅读状态、翻译和搜索历史本地持久化。
- 搜索、收藏、历史和相关论文通过路由栈返回原入口。

### ChatPaper

- DeepSeek Key 已通过独立凭据端口接入安全存储；“我的”支持验证、保存、替换和删除，服务请求运行时读取最新 Key。
- 主聊天和论文聊天统一入口。
- SSE 流式正文和思考内容。
- 深度思考开关、联网搜索、来源展示、停止和重试。
- Markdown、公式和可复制代码块。
- 会话保存、置顶、删除和清空上下文。
- 会话左滑操作与列表项使用一致圆角轮廓，置顶、取消置顶和删除流程保持不变。

### 基础设施

- 唯一应用组合根。
- 业务 Repository 接口与内存测试实现。
- 版本化本地 JSON、schema 迁移、原子替换、损坏隔离和 revision 并发保护。

## 4. 已确认的技术决策

### 远程论文

- 手机端使用 arXiv Atom 查询 API，不把 OAI-PMH 全量同步放入启动流程。
- arXiv Provider DTO、缓存 Record 和领域 `Paper` 必须是不同类型。
- 使用小页分页并缓存；连续 arXiv 请求遵守服务方的节流要求。
- 0.1.0 保持去除版本后缀的裸 arXiv ID，例如 `2404.01356`，避免破坏现有收藏和评论关联。
- OpenAlex 只做非阻塞增强，不影响论文正文加载。

### DeepSeek

- Endpoint、模型和协议参数可以固定，公开 APK 不包含共享 API Key。
- 0.1.0 使用用户自己的 Key；正式实现通过安全凭据 Repository 访问 Android Keystore。
- `dart-define` 只允许私人开发构建回退，不属于上线方案。
- 深度思考关闭时不发送思考预算；开启时默认使用 `high`。
- 聊天、思考内容、评论和阅读记录是设备上的明文本地数据，必须在隐私说明中明确并提供删除入口。

## 5. 必须人工完成的发布门

以下项目不能用 Widget 测试代替：

- DeepSeek 真实 Key 的保存、替换、删除、流式回答和联网搜索。
- Keystore 在重启、升级、卸载和系统备份恢复后的行为。
- Android 分享面板、键盘、后台恢复、离线和弱网。
- 正式上传密钥、签名包安装、旧版本升级和 AAB 验证。
- Play App Signing、Data Safety、隐私政策 URL 和预发布报告。

这些项目在完成前，版本状态只能是“代码候选”，不能标记为“已上线”。

## 6. 剩余发布顺序

1. 由发布者生成并离线备份正式 upload keystore，创建本机 `android/key.properties`。
2. 执行全量静态检查、测试和签名 APK/AAB 构建，记录产物哈希与签名验证结果。
3. 按 [`release-checklist.md`](release-checklist.md) 完成 Android 真机网络、AI、密钥、分享、键盘和升级验收。
4. 发布正式隐私政策 URL，填写 Play Data Safety，并通过内部测试轨道与预发布报告。

长期路线图中的账号、云同步、共享翻译库、服务端 DeepSeek 代理、全文/PDF 阅读器、推荐系统、BibTeX 与引用图谱属于 0.1.0 之后的能力，不计入单机版上线缺口。
