# PaperFlow 0.2.0 文档

> 状态：规划中。
> 最近更新：2026-08-02

0.2.0 重点改造论文发现、索引和深度阅读体验。设计借鉴 Cool Papers 的可寻址分类与会议索引，但继续采用适合手机的信息流界面。

## 已确认计划

- [论文频道、索引与阅读改进计划](paper-channels-and-reading.md)

## 版本目标

1. 将领域筛选升级为用户可添加、删除和排序的论文频道。
2. 分开管理 arXiv 主题频道和 AI 会议频道。
3. 原筛选入口改为时间筛选。
4. 正确展示 Subjects、Publish Time、会议年份和 Track。
5. 将论文内容改为 Abstract、摘要、关键词、作者与单位、AI 解读、相关论文六页。
6. 按需下载并解析 PDF，生成六问 AI 解读并写入本地缓存。
