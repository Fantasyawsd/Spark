# PaperFlow 0.1.0 文档

> 状态：功能代码候选，等待正式签名、Android 真机验收和商店发布门。

0.1.0 是 PaperFlow 的单机首发版本，只包含论文、ChatPaper 和我的三个一级页面。论文频道重构、会议索引和 PDF 六问 AI 解读不计入本版本。

## 冻结范围

- 保持现有远程 arXiv Feed、搜索、分页和离线缓存闭环。
- 保持本地点赞、收藏分组、评论、分享和阅读状态。
- 保持 ChatPaper、DeepSeek BYOK 和本地会话管理。
- 新功能只处理发布阻塞问题，不在 0.1.0 中进行大规模信息架构改造。
