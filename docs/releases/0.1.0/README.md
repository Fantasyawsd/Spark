## 发布内容

0.1.0 是 PaperFlow 的单机首发版本，只包含三个一级页面：

1. **论文**：远程论文流、分类、搜索、阅读、翻译、点赞、收藏、评论和分享。
2. **ChatPaper**：置顶主聊天、按论文建立的聊天、流式回答、深度思考、联网搜索和本地会话管理。
3. **我的**：收藏分组、阅读历史、稍后阅读、主题、AI 凭据和本地数据管理。

社区、私信、通知、账号、云同步和内容发布不进入本版本。论文频道重构、会议索引和 PDF 六问 AI 解读不计入本版本。
