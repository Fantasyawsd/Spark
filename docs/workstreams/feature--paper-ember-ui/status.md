## 实现内容

### 主题与导航

- 亮色画布 `#F6F4EF`、卡片 `#FFFDF9`、正文 `#262A28`；深色画布 `#171C19`、卡片 `#1D2320`。
- 未设置偏好的用户默认使用火花橙 `#B84B2F`；已有五种强调色的持久化枚举名称不变，已保存选择继续生效。
- 深色蓝色微调为 `#228BFF`，与新深色表面搭配通过对比度测试；填充按钮按背景选择文字前景色。
- 系统衬线标题与 16px / 1.8 行高论文正文；不新增字体文件、依赖或字体下载。全文阅读器的字号设置叠加系统文字缩放。
- 更新圆角、触控命中区和安静的实色底栏，保留原有导航及实验功能门控。

### 发现与阅读

- 顶栏拆分品牌/搜索、频道/管理、时间/视图三个层级。
- 新增数据驱动的单篇发现卡，提供开始阅读、收藏/长按分组与稍后阅读。元信息和推荐原因仅使用实际字段。
- 发现页展示原文 Markdown/公式摘要，避免将中文摘要占位文案当成已生成内容；浏览不会主动发起新的 AI 请求。
- 预览不消费信息流的竖向翻页手势；新增真实 drag 测试验证上滑切换论文。双栏、频道位置和分页逻辑保留。
- 阅读器分为“概览 / 解读 / 相关 / 详情”，概览保留 Abstract/摘要切换，详情保留作者/关键词切换。
- 阅读正文可滚动，短文和长文均保留全文入口；短屏及大字号下标题区域可滚动。
- 底栏突出收藏、稍后阅读和 ChatPaper；更多菜单保留点赞、评论、分享、已读与收藏分组。修复长按收藏与 Tooltip 的手势竞争。

### ChatPaper 与我的研究

- 论文聊天显示当前论文上下文，区分“基于论文摘要 / 正在读取全文… / 已读取全文”。全文可读取不等于已经加载。
- 全局与临时聊天不显示论文专属上下文卡；保留原有流式回复、来源、IME、会话设置与存储逻辑。
- 阅读器的 ChatPaper 操作继续复用既有讨论面板回调，未替换会话业务流程。
- 我的研究页将收藏、稍后阅读、历史优先于 API 配置；保留主题、数据与隐私设置。
