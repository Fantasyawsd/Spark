## 2. 问题与边界

`PaperEnhancementMerge.applyEnhancement()` 当前通过重新调用 `Paper(...)` 手工复制约 25 个字段，只覆盖单位、概念和引用数。`Paper` 增加字段时，增强合并不会得到编译器保护，遗漏复制会静默丢数据。本批把完整复制规则集中到 `Paper.copyWith()`，增强扩展只传入真正变化的字段。

保持不变：

- 空增强列表不覆盖原单位或内容关键词。
- 缺失引用数不覆盖原引用数，包括未知 `null`。
- `Paper` 构造器仍对集合创建不可变副本。
- 所有身份、内容、元数据、指标、链接和时间字段在增强后保持原值，除明确增强字段外。

## 3. 验收标准

1. `Paper` 提供覆盖全部当前构造字段的 `copyWith()`，复制结果继续保持集合不可变。
2. `applyEnhancement()` 不再手工枚举全部 `Paper` 字段，只覆盖非空单位、非空概念和非空引用数。
3. 测试使用字段完整的论文实体，证明增强前后所有非目标字段不变、目标字段按规则更新。
4. 空增强不会把已有增强字段清空；缺失引用数不会把已知值变成未知或把未知值伪造为 0。
5. 定向测试、`flutter analyze`、格式门禁和 `/test` 全量门禁全部通过。
